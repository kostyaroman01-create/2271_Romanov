*Рассмотрите следующие фрагменты программ. Запишите, что означают символы* **&** и  * *в каждом случае применения.*

* & - взятия адреса

* в третьей строчке q присваивается указатель p
* четвертая строчка * берет число с указателя

* вторая программа

   }
