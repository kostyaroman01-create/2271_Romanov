# Задание 1
Усреднение последовательности
Задана последовательность a1...an из n вещественных чисел, представляющая результаты некоторых измерений. К этой последовательности m раз применяется фильтр скользящего среднего глубины 3. При однократном применении этого фильтра первый элемент a1 заменяется на (2a1+a2)⁄3, аналогично последний элемент an заменяется на (2an+an-1)⁄3, а все остальные элементы ai заменяются на (ai-1+ai+ai+1)⁄3. Все замены должны выполняться одновременно. Например, в результате однократного применения фильтра к последовательности 1 4 7 4 должна получиться последовательность 2 4 5 5.

Ваша задача — вывести результат применения описанного фильтра m раз к исходной последовательности.

Формат входных данных
В первой строке записаны два натуральных числа n и m, 3≤n≤1000, 1≤m≤10. В следующей строке через пробел записаны n вещественных чисел, не превосходящих по модулю 1000 не более чем с 3 знаками после точки.

Формат результата
Вывести в одной строке через пробел n вещественных чисел — результат применения описанного фильтра m раз. Погрешность не должна превышать 10-4.

Примеры
Входные данные
4 1
1.0 4.0 7.0 4.0
Результат работы
2.0 4.0 5.0 5.0
Входные данные
3 2
1.0 4.0 4.0
Результат работы
2.333333 3.0 3.666667

Сортировка по абсолютному значению

В первой строке записано одно натуральное число n — количество чисел в последовательности. 1≤n≤100000. В следующей строке через пробел записаны n целых чисел, принадлежащих последовательности. Каждое число не превосходит 109 по абсолютной величине.

# Задание 3
Гербафрика
В рассказе "Взамен политики" замечательной русской писательницы Тэффи семейство играет в такую игру. Выбирается некоторое слово русского языка, которое можно разбить на два других слова, например, гимназия=гимн+азия, далее каждое из полученных слов заменяется на некоторое другое слово близкое по смыслу, например, гимн - герб, азия - африка. После этого, вместо слова гимназия говорим гербафрика.

Ваша задача — используя заданный набор слов, найти замену для данного слова.

Формат входных данных
В первой строке записано слово для которого требуется найти замену. Во второй строке записано одно натуральное число n — количество пар слов в словаре, 2 ≤ n ≤ 100. Далее в 2n строках записано n пар слов: слово и в строке ниже замена для него.

Гарантируется, что исходное слово может быть разбито ровно на два слова из первых элементов пар словаря ровно единственным образом. Каждая строка состоит не более чем из 32 символов.

Формат результата
Вывести одно слово — результат замены.

Примеры
Входные данные
gimnazia
4
kniga
gazeta
azia
afrika
mama
papa
gimn
gerb
Результат работы

# Задание 4
Транспонирование матрицы
Матрицей называется прямоугольная табличка из чисел, состоящая из n строк и m столбцов. Элемент матрицы который находится в строке i и столбце j обозначается aij. Результатом транспонирования такой матрицы будет матрица из m строк и n столбцов у которой элемент aij будет находиться на пересечении строки j и столбца i.

Вы должны написать программу для транспонирования заданной матрицы.

Формат входных данных
В первой строке записано два натуральных числа n и m — Количество строк и столбцов матрицы. 1≤n≤100, 1≤m≤100. Далее в n строках записаны по m целых чисел aij. Числа не превосходят 10 по модулю.

Формат результата
В m строках и n cтолбцах выести матрицу после транспонирования.

Примеры
Входные данные
3 4
1 4 2 3
2 5 1 7
5 6 1 9
Результат работы
1 2 5
4 5 6
2 1 1
3 7 9

# Задание 5
Дроны и горностаевая моль
В городе Энске есть большой парк прямоугольной формы. Некоторые из деревьев в этом парке необходимо обработать от вредителей, таких как горностаевая моль. Известны координаты на плоскости всех деревьев, нуждающихся в обработке. Специальный дрон будет двигаться от одного дерева к другому и обрабатывать их инсектицидными аэрозолями. Но для дрона необходимо составить маршрут движения, по возможности близкий к оптимальному.

Было решено использовать следующий алгоритм. Зададим координаты так, что левый нижний угол парка будет находиться в точке (0;0), а правый верхний — в точке (w;h). Разделим получившийся прямоугольник на вертикальные полосы шириной s. Последняя полоса может иметь меньшую ширину. Пронумеруем все полосы числами от нуля. Будем считать, что точка принадлежит полосе с номером k, если для ее координаты x выполняется неравенство ks ≤ x < (k+1)s. Сначала дрон обработает все деревья, попавшие в нулевую полосу, потом в первую и так далее.

Двигаясь по полосам с четными номерами, дрон будет обрабатывать деревья в порядке возрастания их координаты y. Если же номер полосы будет нечетным, то дрон будет двигаться в порядке убывания координаты y. Если координаты y у двух деревьев в пределах одной полосы совпадут, то дрон будет обрабатывать их в порядке возрастания координаты x вне зависимости от четности номера полосы.

Обратите внимание, что алгоритм будет исполняться формально, то есть на его исполнение, например, не окажет влияние отсутствие деревьев в некоторых полосах или то, что последняя полоса будет иметь ширину 1. Чтобы лучше понять алгоритм движения, посмотрите на схему ниже. Здесь пять полос, в нулевую полосу попали все деревья с координатой x в полуоткрытом интервале [0; 5). Эти деревья обходятся снизу вверх. В первую и третью полосу попали деревья с координатой x из полуоткрытых интервалов [5, 10) и [15; 20). Деревья в этих полосах обходятся сверху вниз. Последняя полоса содержит только деревья с координатой x = 20.

Напишите программу, которая по заданным координатам деревьев найдет длину пути дрона от первого обработанного дерева до последнего.

Формат входных данных
В первой строке на вход программы поступают три целых числа w, h, s — размеры парка по оси Ox, по оси Oy и ширина полосы, (1 ≤ w, h, s ≤ 10000). Во второй строке на вход программы поступает одно натуральное число n — количество деревьев в парке, (2 ≤ n ≤ 200000). Далее в n строках записаны по два числа xi и yi — координаты на плоскости каждого из n деревьев, (0 ≤ xi < w), (0 ≤ yi < h).

Формат результата
Выведите одно вещественное число — расстояние пройденное дроном от первого дерева в маршруте до последнего. Ответ будет считаться верным, если он будет отличаться от точного значения не более чем на 10−3.
