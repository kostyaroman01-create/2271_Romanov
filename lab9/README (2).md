*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```
```
def gen(n):
    yield n
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        yield n
print (*gen(7))
```

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

. Что передается в функцию toint и что она возвращает?

• Что передается: В функцию передается другая функция fun (объект функции), которую мы хотим модифицировать (декорировать).
• Что возвращается: Функция возвращает новую функцию-обёртку wrapper. Сама исходная функция fun при этом не вызывается, а «запоминается» внутри замыкания (closure) для последующего использования.

2. Что делает функция wrapper?

Функция wrapper перехватывает любые позиционные аргументы (*args), переданные декорированной функции, и делает следующее:
1. map(int, args) — приводит каждый переданный аргумент к целому числу (тип int). Например, если передать строки '5' и '10', они превратятся в числа 5 и 10.
2. *... (распаковка) — передает эти преобразованные целые числа в исходную функцию fun.
3. return — возвращает результат работы исходной функции fun.
Простыми словами, wrapper гарантирует, что исходная функция гарантированно получит на вход чистые целые числа (int), даже если пользователь передал их в виде строк или чисел с плавающей точкой (float).

3. Примеры использования toint


Пример 1: Использование в качестве классического декоратора

Представим функцию, которая умеет складывать только числа. Если передать строки, Python выдаст ошибку или просто склеит их ('5' + '7' = '57'). С декоратором toint она всегда будет выполнять математическое сложение:
python
@toint
def add(a, b):
    return a + b

# Проверяем работу:
print(add("5", "7"))      # Выведет: 12 (строки автоматически стали int)
print(add(4.9, 3.1))      # Выведет: 7 (float округлились до int: 4 + 3)
print(add(10, 20))        # Выведет: 30 (обычные int работают как надо)
Используйте код с осторожностью.

Пример 2: Динамическое оборачивание стандартных функций

Вы можете обернуть стандартные функции Python «на лету» без использования синтаксиса @:
python
# Оборачиваем стандартную функцию sum, чтобы она принимала строки
sum_of_strings = toint(sum)

# Стандартный sum(['1', '2']) выдал бы ошибку TypeError.
# Наша обернутая функция отлично справляется, если передать аргументы через запятую:
print(sum_of_strings("10", "20", "30"))  # Выведет: 60
Используйте код с осторожностью.

Пример 3: Безопасное вычисление площади

Функция, которая рассчитывает площадь прямоугольника по введенным пользователем данным (которые из input() всегда приходят как строки):
python
@toint
def get_area(width, height):
    return width * height

# Имитируем ввод от пользователя (пришли строки)
user_width = "15"
user_height = "4"

print("Площадь:", get_area(user_width, user_height))  # Выведет: Площадь: 60
