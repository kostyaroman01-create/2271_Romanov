*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```
```
def gen(n):
    yield n
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        yield n
print (*gen(7))
```

*Самостоятельно познакомьтесь с понятием декораторов в Python. Приведите примеры использования

* Декоратор — это функция, которая принимает другую функцию и возвращает новую функцию (обёртку), обычно расширяя или изменяя поведение исходной, не трогая её код.
```
python
@decorator
def f():
    ...
```
эквивалентно
```
python
def f():
    ...
f = decorator(f)
```
Наша toint — классический декоратор: принимает fun, возвращает wrapper, который приводит все позиционные аргументы к int и вызывает fun.
```
python
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
Примеры использования toint как декоратора
1. Сложение чисел, поданных строками
```
@toint
def add(a, b):
    return a + b

print(add('2', '3'))      # 5   (без декоратора было бы '23')
print(add(10, 20))        # 30
```
2. Сумма произвольного числа аргументов
```
@toint
def total(*nums):
    return sum(nums)

print(total(*input().split()))   # ввод: 2 5 11 3 8  →  29
Здесь *input().split() 
```
* даёт строки, а wrapper превращает их в int до вызова total.
3. Сравнение как чисел, а не строк
```
@toint
def biggest(a, b):
    return max(a, b)

print(biggest('3', '17'))   # 17  (без декоратора max('3','17') = '9'... то есть '3'<'17'? нет: '3' > '17' → '3')
```
* Точнее: строковое сравнение дало бы '3' (потому что '3' > '1'), а с декоратором — 17. Наглядно видно, зачем приводить к int.
### Задание 2 **(3)**
*Напишите фрагмент программы, которая найдет в списке слов слово с максимальной длиной. При равенстве длин
найдет самое первое в лексикографическом порядке.*

*Фрагмент программы должен состоять из одного вызова функции* **min** *или* **max**.
### Задача
* Найти слово:
1. максимальной длины;
2. при равенстве длин — лексикографически наименьшее (самое первое в алфавитном порядке).
3. Ограничение: ровно один вызов min или max.

* Идея
1. max с ключом key. Ключ должен:
2. в первую очередь максимизировать длину;
3. при равной длине — минимизировать слово (лексикографически).

* Хитрость: чтобы «перевернуть» сравнение строк внутри max, нельзя просто взять -len, потому что строки не инвертируются. Но можно использовать тот факт, что кортежи сравниваются поэлементно, и подобрать ключ вида (len(w), ???), где ??? инвертирует порядок строк.

* Инверсия строки в лексикографическом порядке — нетривиальна. Проще всего — два прохода не нужны, а нужен min с «обратным» ключом по длине:
```
python
min(words, key=lambda w: (-len(w), w))
```
* Как это работает
1. min ищет минимум по ключу (-len(w), w).
2. -len(w) — чем длиннее слово, тем меньше -len. Поэтому min предпочитает самые длинные слова (у них наименьший -len).
3. При равной длине -len одинаков, и сравнение переходит ко второму элементу — самому слову w. min выбирает лексикографически наименьшее слово. ✅
4. Ровно то, что нужно: максимальная длина + первое по алфавиту при равенстве.
```
words = ['кот', 'собака', 'дом', 'енот', 'бык', 'крот']

print(min(words, key=lambda w: (-len(w), w)))
# len: кот=3, собака=6, дом=3, енот=4, бык=3, крот=4
# max длина = 6 → 'собака'
# → 'собака'
```
```
words = ['abc', 'xyz', 'def']
print(min(words, key=lambda w: (-len(w), w)))
# -len одинаков, min по слову → 'abc'
```
